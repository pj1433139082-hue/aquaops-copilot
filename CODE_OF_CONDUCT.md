# Code of conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful, assume good faith, criticise ideas rather than people,
and do not harass anyone. Maintainers may remove comments, close threads, or
block accounts that violate these expectations.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact
listed on the GitHub profile of the repository owner. Reports are reviewed and
handled confidentially.
